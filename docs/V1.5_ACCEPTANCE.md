# Pattern Layout Studio V1.5 Acceptance

Date: 2026-09-27

## Regression source

Acceptance uses the user-supplied 2048×2048 illustrated pattern sheet `6.png`. The image is not committed to the public repository.

## 1. Rectangle contamination regression

The source produces **32 significant connected components** before host-aware grouping and **27 logical parts** in Conservative mode.

Under the old bounding-rectangle extraction model, **14 logical-part rectangles** contain foreground pixels belonging to other components.

Across those rectangles, approximately **23,289 unrelated foreground pixels** are inside the crop bounds.

V1.5 uses the component-label map and allowed-label sets, so those unrelated pixels are excluded from each local part mask.

- [x] bbox remains crop bounds only
- [x] unrelated labels inside bbox are zeroed
- [x] neighbouring parts cannot leak into one another

## 2. Face / internal colour regression

The face-like logical region has approximately **59k thresholded foreground pixels** before interior restoration.

The enclosed-interior pass restores approximately **82k additional pixels** inside the closed face silhouette before original RGB is composited.

This is the intended behavior: internal skin / blush / eye-area colours are preserved even when close to the global background colour.

- [x] border-connected background remains transparent
- [x] enclosed interior colour is preserved
- [x] final RGB comes from raw source pixels
- [x] internal colour is not replaced by generated colour

## 3. Source trace

- [x] automatic parts store exact source contours
- [x] SVG source overlay uses contours rather than bbox by default
- [x] responsive display does not change mapping accuracy
- [x] merged parts retain multiple contours
