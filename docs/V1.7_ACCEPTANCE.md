# Pattern Layout Studio V1.7 Acceptance

Date: 2026-09-27

## Multi-file input

- [x] file input accepts multiple images
- [x] one image is still supported
- [x] multiple files are converted to an ordered source list
- [x] files are processed sequentially
- [x] progress identifies current source index and filename

## Unified project layout

- [x] source images are not independently paginated
- [x] all successful sources contribute to one `allParts` array
- [x] unified MaxRects runs after all extraction completes
- [x] global page compaction runs across parts from different sources
- [x] cross-source parts may share one output page
- [x] no-scale invariant remains unchanged

## Provenance

- [x] every automatically extracted part has a source ID
- [x] every automatic part records a source region
- [x] exact contours remain in source-image coordinates
- [x] selecting a part can switch the source preview automatically
- [x] source thumbnails allow manual source switching
- [x] debug previews follow the active source

## Cross-source merge / split

- [x] merge retains source regions from every contributing source
- [x] boxes from different sources are not unioned into one coordinate system
- [x] a merged multi-source part can be inspected source by source
- [x] selection remains stable when switching between valid sources
- [x] split refines a single-source mapping when exact
- [x] ambiguous multi-source split preserves provenance instead of inventing coordinates

## Partial batch failure

- [x] one failed source does not discard successful sources
- [x] failed source count is displayed
- [x] zero successful sources produces a batch error

## Regression gates

- [x] V1.6 cross-page transfer retained
- [x] V1.6 global compaction retained
- [x] V1.5 exact masks retained
- [x] internal RGB preservation retained
- [x] brush / eraser retained
- [x] atomic split retained
- [x] current-page PNG retained
- [x] all-pages ZIP retained
- [x] DPI metadata retained

## Build / deployment gate

Release is accepted only after:

- npm install: success
- npm run build: success
- Pages artifact upload: success
- GitHub Pages deploy: success
