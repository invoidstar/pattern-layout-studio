# Pattern Layout Studio V1.3 Acceptance

Date: 2026-09-27

## User regression case

The reported regression is a dense 2048x2048 pattern sheet containing many independent illustrated parts.

The V1.2 behavior could show `overflow` when one MaxRects page did not accept every extracted part.

V1.3 changes the acceptance criterion:

> Failure to fit on the current page is not an error. The part must be retried on the next page.

The private source image is not committed to this repository.

## Multi-page packing acceptance

- [x] First page is generated with MaxRects.
- [x] Unplaced parts are retried on page 2.
- [x] Paging continues until no ordinary part remains.
- [x] Part width/height are never scaled to make a page fit.
- [x] Page indexes are consecutive.
- [x] Current page can be viewed independently.
- [x] Previous / next navigation clears transient editing selection.
- [x] Complete project can be repacked with one action.

## Edge-size acceptance

V1.3 differentiates two cases.

### Fits canvas but not normal packing gap

If the part itself is within the target width/height, it receives a dedicated centered page.

This prevents a near-canvas-size part from being incorrectly labelled overflow simply because the normal packing gap cannot be preserved.

### Truly larger than canvas

Only when:

```
part.width > canvas.width
or
part.height > canvas.height
```

may the part remain unplaceable.

The UI reports these separately as **超大零件**, not ordinary page overflow.
