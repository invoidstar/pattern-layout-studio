# Pattern Layout Studio V1.4 Implementation

Date: 2026-09-27

## Goal

V1.4 adds explicit provenance visualization for every converted part and reorganizes the interface around the real workflow:

**original image → extracted part → layout page**

## Source metadata

Each automatic extraction already has a crop bounding box in original-image coordinates. V1.4 promotes that metadata into a first-class UI feature.

`PartStats` now supports:

- `sourceBox`
- `sourceBoxes[]`

The array form allows a single logical/merged part to originate from multiple distinct regions of the original image.

## Original-image reference

The App retains a browser-local reference to the uploaded original:

- file data URL
- original width
- original height
- filename

This data is used only for the Source Trace panel and is not sent to the repository.

## Interactive source map

The left Source Trace panel renders the original image at responsive scale.

For each part on the active layout page:

- source coordinates are converted to percentage positioning
- a lightweight rectangle is drawn over the original image
- clicking the rectangle selects the corresponding converted part
- selected parts receive a high-contrast source highlight

Because positioning uses percentages derived from original pixel coordinates, mapping remains correct at any UI display scale.

## Coordinate details

For a selected part, the UI lists:

- x
- y
- width
- height

in original-image pixels.

For a manually merged part, every contributing original region is listed separately.

## Merge / split provenance

### Merge

Manual Merge concatenates the selected parts' `sourceBoxes`.

A union bounding box is also stored for compatibility, while the UI keeps the individual source regions visible.

### Split

If the parent has exactly one source region, the new child region can be mapped exactly by adding the local split-box offset to the parent original coordinates.

If the parent was previously merged from multiple original regions, children conservatively inherit the multiple-region provenance rather than inventing an incorrect exact mapping.

## UI refresh

V1.4 changes the desktop workspace from two columns to three:

- Source Trace: 300 px
- Canvas Editor: flexible central workspace
- Parts / Quality: 330 px

Responsive breakpoints:

- medium: Source + Canvas with Parts below
- small: single-column workflow

Debug masks were moved out of the Parts panel and into Source Trace, where they are contextually related to the original image.

## Existing features preserved

- V1.3.1 host-aware grouping
- text removal / optional OCR
- smooth contour and hole preservation
- multi-page MaxRects
- current-page PNG
- all-pages ZIP
- manual repair
- Undo / Redo
- no-scale dimensions
- DPI metadata
