# Pattern Layout Studio V1.1 Acceptance

Date: 2026-09-27

This acceptance round validates the V1.1 browser-side pipeline against three real user-supplied images. The source images are **not committed** to the public repository.

## Scope

- Robust background estimation from the full outer border
- Adaptive foreground threshold
- 3×3 majority cleanup
- 8-connected component extraction
- 2 px crop padding without resizing
- Multi-strategy MaxRects packing
- 1:1 pixel-size preservation
- Both output canvases: 2970×2100 and 3500×3500

## Real-image cases

| Case | Source size | Background | Expected / detected major parts | V2 threshold | Clean foreground | 2970×2100 | 3500×3500 |
| --- | ---: | --- | ---: | ---: | ---: | --- | --- |
| A | 2048×2048 PNG | White | 10 / 10 | 22.0 | 25.7% | 10/10, 0 overflow | 10/10, 0 overflow |
| B | 1810×1280 JPEG | White, foreground touches border | 10 / 10 | 22.0 | 50.4% | 10/10, 0 overflow | 10/10, 0 overflow |
| C | 1280×1280 JPEG | Gray | 11 / 11 | 22.0 | 52.3% | 11/11, 0 overflow | 11/11, 0 overflow |

Case B is important because a foreground rectangle reaches the right edge. Four-corner / mean background sampling is fragile here; the V2 border-median estimator still resolves the background as RGB(255,255,255). Case C verifies that the method is not hard-coded to white backgrounds; it resolves RGB(113,113,113).

## Packing V2 results

All three real-image cases fit without resizing on both target canvases.

| Case | 2970×2100 strategy | Utilization | 3500×3500 strategy | Utilization |
| --- | --- | ---: | --- | ---: |
| A | width | 25.8% | height | 13.2% |
| B | max-side | 27.9% | height | 14.2% |
| C | area | 20.6% | area | 10.5% |

The strategy is selected automatically from area, max-side, height and width orderings using MaxRects Best-Short-Side-Fit.

## Acceptance verdict

- [x] White-background PNG segmentation
- [x] JPEG compression tolerance
- [x] Foreground touching an image edge
- [x] Non-white solid background
- [x] Expected major-component count preserved on all three cases
- [x] 2970×2100 packing with zero overflow
- [x] 3500×3500 packing with zero overflow
- [x] Packing does not modify part width or height
- [x] App exposes segmentation and packing diagnostics
- [x] Export path still validates no-scale fit before PNG creation

## Remaining limitations

V1.1 is designed for approximately solid backgrounds. Highly textured/photo backgrounds, touching parts that are physically connected by foreground pixels, and semantic splitting of a single connected shape are outside this acceptance scope and should be treated as later segmentation modes rather than silently guessed.
