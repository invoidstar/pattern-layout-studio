# Pattern Layout Studio V1.3.1 Acceptance

Date: 2026-09-27

## Regression addressed

A dense illustrated 2048×2048 pattern sheet exposed a new V1.3 issue: disconnected artwork inside a larger logical part could be interpreted as an independent part.

Typical examples include:

- a small emblem printed on clothing;
- facial details inside the face piece;
- inner highlight/detail islands inside a bow;
- other small decorative islands that visually belong to a much larger host.

The source image is user-supplied and is not committed to the public repository.

## Host-aware grouping

V1.3.1 adds a second stage after significant connected-component extraction:

`connected components → host-aware grouping → logical parts`

A small component can be merged into a larger host only when:

- the host is substantially larger;
- the small component/host area ratio is below the mode threshold;
- the small component centre lies inside or immediately at the host bounding region;
- the candidate host itself is a meaningful major component.

The smallest valid enclosing host is chosen to keep grouping local.

## Split-strength modes

| Mode | Behaviour |
| --- | --- |
| Conservative | Default. Prefer keeping internal artwork with the host part. |
| Standard | Moderate grouping. |
| Fine | Preserve more disconnected detail as independent parts. |

## Real-image regression result

For the reported 2048×2048 illustrated sheet:

- significant components before host grouping: **32**
- logical parts after Conservative grouping: **27**
- automatically merged internal components: **5**

The merged groups include the clothing-internal emblem/detail and other contained decorative islands. Large standalone hair pieces, ears/accessories, weapons and other genuinely separate parts remain independent because they are not small contained children of a host.

## Multi-island rendering

Grouping disconnected components would normally expose another failure mode: a renderer that traces only one outer contour could drop the merged decoration.

V1.3.1 therefore renders **all disconnected foreground islands** inside one logical part:

- each outer island gets its own contour;
- all contours are smoothed independently;
- legitimate inner holes remain preserved;
- even-odd filling keeps holes transparent while retaining contained decorative islands.

## Remaining boundary

Spatial grouping cannot infer arbitrary artistic semantics. When two genuinely independent parts are intentionally drawn inside the bounding box of another much larger part, switch to Standard/Fine or use the existing manual Split workflow.
