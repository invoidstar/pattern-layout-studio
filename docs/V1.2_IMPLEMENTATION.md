# Pattern Layout Studio V1.2 Implementation

Date: 2026-09-27

## Goal

V1.2 turns the V1.1 foreground extraction into a deliverable part-extraction workflow:

1. exclude annotation text,
2. repair fragmented / noisy edges,
3. preserve no-scale dimensions,
4. provide manual repair tools when automation is imperfect.

## Final pipeline

```
Upload
  -> dominant-border background model
  -> initial foreground mask
  -> conservative geometry text-line filter
  -> optional Chinese/English OCR enhancement
  -> closing / opening
  -> tiny-island removal
  -> small-hole fill
  -> 8-connected component extraction
  -> outer + inner contour tracing
  -> Chaikin contour smoothing
  -> supersampled antialiased alpha
  -> MaxRects no-scale packing
  -> manual repair
  -> PNG + pHYs DPI export
```

## Text exclusion

### Default geometry filter

The default path does not delete a component merely because it is small.

A candidate must:

- stay below conservative size/area limits,
- be away from protected large parts,
- belong to a horizontal text-like cluster.

Once a cluster is confirmed as a text line, its tight region is cleared to remove thicker residual strokes.

### OCR enhancement

Optional OCR enhancement uses Tesseract.js with English + Simplified Chinese language data. It is lazy-loaded only when enabled. OCR failures do not block processing; the application falls back to the geometry filter.

## Edge cleanup

The morphology pipeline provides three modes:

- off,
- standard (default),
- strong.

Standard mode performs:

- 5x5-equivalent binary closing,
- 3x3 opening,
- adaptive tiny-island removal,
- adaptive small-hole fill.

Strong mode uses larger cleanup radii.

## Contour / alpha rendering

Each part receives:

- ordered outer-contour tracing,
- enclosed-hole contour tracing,
- Chaikin smoothing,
- supersampled rasterization,
- even-odd fill so legitimate internal holes stay transparent,
- antialiased final alpha.

The logical part width/height are not resized.

## Manual repair

V1.2 includes:

- Select / multi-select
- Drag
- Lock / unlock
- Brush restore
- Eraser
- Merge
- Split disconnected alpha regions
- Delete
- Undo / Redo
- Ctrl/Shift multi-select
- Ctrl+Z / Ctrl+Shift+Z shortcuts

The brush restores only the text-filtered source foreground, so it does not paint the original background back into the part.

## Debug view

The UI can display:

- raw foreground mask,
- mask after text exclusion,
- smoothed mask,
- detected text regions.

It also reports text count, morphology cleanup statistics, final part count, packing strategy and utilization.

## Output invariants

- No packing resize
- No editor resize
- 3500x3500 output
- 2970x2100 output
- configurable DPI
- PNG pHYs metadata
- export is blocked while any part is outside the target canvas
