# Pattern Layout Studio V2.0 — Implementation

Date: 2026-10-09

## Release scope

V2.0 is a workbench/UI and infrastructure refresh. It intentionally preserves the V1.8.1 vision, provenance, packing, and export algorithms.

## Desktop layout

- Compact brand + announcement navigation
- Project toolbar shows source, part, and page counts
- One-click image import, processing settings, and export dialog
- Left Source Trace, central Canvas, right Inspector
- Page strip, zoom / fit, and concise tool controls
- Processing diagnostics moved into collapsible sections

## Mobile-specific interaction

- Dedicated bottom navigation for Canvas / Source / Parts
- Only one main work area visible at a time at phone widths
- Canvas mode buttons: select, pan, restore brush, eraser
- Pinch zoom + one-finger pan while Pan mode is active
- Zoom control: minus, plus, fit
- Tool and output interactions retain original part coordinates
- Safe-area-aware mobile bottom navigation and dialogs

## Announcements

- `src/content/announcements.ts`: typed release data
- `src/components/AnnouncementCenter.tsx`: lightweight banner, history and detail dialog
- Latest release ID persisted in localStorage on dismissal
- New release ID triggers a new banner
- No forced modal on ordinary page loads
- Header entry always opens history

## Analytics (deferred by request)

- Added `src/services/analytics/index.ts` with an `AnalyticsClient` interface
- Default client is disabled and creates no tracking request or visitor ID
- Future `createWorkerAnalyticsClient({ endpoint })` adapter exposes `recordVisit()` and `getSummary()`
- No Cloudflare Worker, D1 database, or production analytics API is deployed in V2.0
- The UI never displays fabricated PV/UV

## Styles

Removed historical V1.x CSS override sections, replacing them with:

- `tokens.css`
- `base.css`
- `workspace.css`
- `dialogs.css`
- `announcements.css`
- `mobile.css`

Breakpoints intentionally separate desktop, tablet, and mobile rather than stacking all desktop columns on a phone.

## Preserved features

- Multi-image input and A4 / 3500×3500 dimension gate
- Geometry text filtering and optional OCR
- Exact component membership and RGB preservation
- Host-aware decorative island grouping
- Original source contour tracking
- Global MaxRects and cross-page backfill
- Manual drag, merge, split, locking, brush/eraser, undo/redo
- PNG current-page and ZIP all-pages export with DPI metadata
- No-scale placement

## Verification and deployment

The repository is hosted exclusively through GitHub Pages. The `.github/workflows/pages.yml` workflow on `main` runs dependency installation, TypeScript verification, production build, artifact upload, and Pages deployment.

The Chromium smoke suite covers desktop navigation, release notes, settings/export dialogs, mobile navigation and overflow, source-size gating, synthetic image processing, part selection, and preview zoom. This automated suite does not replace review of diverse real pattern sheets.
