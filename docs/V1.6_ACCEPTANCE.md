# Pattern Layout Studio V1.6 Acceptance

Date: 2026-09-27

## Cross-page transfer

- [x] one selected part can move from a later page to an earlier page
- [x] multiple selected parts can move together
- [x] destination page is repacked before state mutation
- [x] move is rejected when the complete destination set cannot fit
- [x] source page is repacked after removal
- [x] empty pages are removed
- [x] page indexes are normalized
- [x] selection follows moved parts
- [x] move can target a newly created page
- [x] operation is Undo-compatible
- [x] no part width / height changes

## Global page optimization

- [x] normal V3 multi-page MaxRects still runs first
- [x] complete page merge is attempted
- [x] later-page items are backfilled into earlier pages
- [x] every accepted backfill revalidates the full destination page
- [x] source page is revalidated after removal
- [x] empty pages are removed automatically
- [x] optimizer has a finite safety guard
- [x] no rotation / scaling is introduced

## Utilization controls

- [x] packing gap is adjustable
- [x] default gap is 16 px
- [x] page chips display utilization
- [x] current page displays live utilization
- [x] overall page-set utilization is displayed
- [x] global optimization can be explicitly rerun after a gap change

## UI

- [x] command controls are compacted into a sticky toolbar
- [x] Canvas is the central visual focus
- [x] page strip is visible directly above Canvas
- [x] Inspector starts with cross-page actions
- [x] page optimization controls are colocated with page movement
- [x] Source Trace remains independent on the left
- [x] responsive two-column and single-column layouts remain available

## Regression gates

- [x] V1.5 exact-mask extraction retained
- [x] internal RGB preservation retained
- [x] source-contour mapping retained
- [x] text filtering retained
- [x] host-aware grouping retained
- [x] brush / eraser retained
- [x] Split parent-replacement retained
- [x] current-page PNG retained
- [x] all-pages ZIP retained
- [x] no-scale invariant retained

## Build / deployment gate

- npm install: success
