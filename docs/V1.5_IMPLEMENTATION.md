# Pattern Layout Studio V1.5 Implementation

Date: 2026-09-27

## Goals

V1.5 fixes four related extraction / editing problems:

1. bounding-rectangle crops could include unrelated neighbouring foreground;
2. face / garment colours could become accidental alpha holes;
3. Split could appear to leave the parent part behind;
4. brush / eraser interaction was sparse and difficult to control.

## 1. Exact component membership

File: `src/core/segmentation.ts`

New pipeline:

```
binary mask
 -> 8-connected component labels
 -> host-aware logical groups
 -> group member label IDs
 -> exact local mask from allowed labels
```

New APIs:

- `labelComponents()`
- `groupLabeledComponents()`
- `localMaskFromLabels()`

The label map is the key change. A logical part no longer means "everything foreground inside this rectangle". It means "only pixels whose connected-component label belongs to this logical group".

Bounding boxes now define crop storage only.

## 2. Internal colour preservation

Files:

- `src/core/segmentation.ts`
- `src/core/alpha.ts`

`fillEnclosedInterior()` flood-fills background starting from the local crop border.

- background connected to the crop border remains transparent;
- zero regions fully enclosed by the logical part are restored into the silhouette.

The final RGB always comes from the raw source crop. Therefore an interior skin / garment colour that happens to be close to the global background colour remains visible instead of becoming transparent.

## 3. Exact alpha / source contours

File: `src/core/alpha.ts`

New entry point:

- `renderPartFromLocalMask()`

It receives the exact local membership mask rather than a global mask + rectangular crop.

It returns:

- final PNG
- masked source PNG
- raw source crop PNG
- exact original-image source contours

The Source Trace UI renders the contours as SVG polygons. Bounding rectangles remain a fallback and coordinate summary only.

## 4. Split parent replacement

File: `src/App.tsx`

Split now uses one atomic `flatMap` state update:

```
parent -> [child1, child2, ...]
```

The parent is never appended alongside the children.

The parent image is also removed from the image cache after replacement.

When a single exact source box exists, child contours are reconstructed from the child alpha mask and mapped back into original-image coordinates.

## 5. Brush rewrite

File: `src/App.tsx`

The old brush applied one isolated circle for every pointer event. Fast motion therefore produced visible gaps.

V1.5 stores the previous local pointer coordinate and interpolates dabs along every movement segment.

Spacing:

```
max(1 px, brushSize * 0.18)
```

Restore brush source:

```
rawSourceImageUrl
 -> sourceImageUrl
 -> current image fallback
```

This means the brush can restore original RGB that was previously outside the current alpha mask.

Automatic crops now receive a 10 px transparent repair margin instead of 3 px, giving the brush room to reconstruct an edge that was cut too tightly.

## 6. Source trace

Source Trace now prefers `sourceContours`.

Each contour is rendered using original-image coordinates in an SVG `viewBox`, so the overlay remains exact at any responsive display size.

Merged parts concatenate contributing contours.

## 7. Retained invariants

- no part resizing
- multi-page layout
- current-page PNG
- all-pages ZIP
- DPI metadata
- text exclusion
- host-aware grouping
- manual merge / split
- Undo / Redo
