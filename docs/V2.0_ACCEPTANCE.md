## Verification gates

Automated verification should include:

- strict TypeScript typecheck
- Vite production build
- Chromium desktop navigation and notices
- mobile 390px navigation and no horizontal overflow
- synthetic 2970×2100 image upload and part extraction
- canvas zoom and selected-part inspector
- invalid image dimensions notice

The production release is only complete after the final `main` commit receives a successful GitHub Pages build and deployment.

## Limitations

- Browser smoke uses synthetic data; artistic and complex real-image quality still needs separate human review.
- The frontend statistics adapter does not imply that the deferred Worker/D1 service exists.
- The editor operates on current browser state; there is no cloud project save service.
