# Pattern Layout Studio V1.2 Acceptance

Date: 2026-09-27

Real user-supplied images were used locally for acceptance. The source images are not committed to the public repository.

## What changed compared with V1.1

### Text

Case A contains exactly three visible Chinese annotation lines. The default geometry filter identifies three text-line regions and removes them without enabling OCR. No-text cases B-E trigger zero geometry text regions.

### Fragmented edges

Case E is the most useful stress case: the thresholded JPEG produces 87 raw foreground connected components, while V1.2 cleanup returns 11 intended major parts.

This demonstrates that the cleanup path is removing edge fragments rather than exposing each fragment as a separate layout part.

### Border contamination

Case A contains a large foreground-coloured strip touching an entire image edge. V1.2 uses a dominant border-colour cluster rather than computing tolerance from every border sample. The background remains the gray field instead of allowing the coloured strip to inflate the threshold.

## Remaining boundary

V1.2 targets solid or near-solid-background pattern sheets. It deliberately avoids pretending to solve semantic segmentation for arbitrary photographic backgrounds. When two intended parts are truly connected in the source pixels, use the eraser + split workflow.
